# Online Mutual Fund Portal

## Project Description

The **Online Mutual Fund Portal** is a web-based application that allows users to register and log in, browse and search mutual fund schemes, view fund details, compare funds, invest in mutual funds, manage their investments, and view transaction and investment history.

The administrator can manage mutual fund schemes, update fund information, monitor user investments, and manage customer transactions.

## Main Features

### User Features

* User registration and login
* Browse mutual fund schemes
* Search and filter mutual funds
* View mutual fund details
* Compare different mutual funds
* Invest in mutual funds
* View investment portfolio
* View transaction history
* Track investment performance

### Administrator Features

* Admin login
* Add, update, and remove mutual fund schemes
* Manage fund information
* Manage user accounts
* Monitor investments and transactions
* Manage system data
